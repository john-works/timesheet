1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
This is a customized installation of Kimai 2.56.0, an open-source time-tracking
application (Symfony + PHP + MariaDB), branded as "PPDA Timesheet" for the
Public Procurement and Disposal of Public Assets Authority (PPDA), Uganda.

Core concepts:
  - Users belong to Teams; Teams access Departments, Projects, and Activities.
  - Timesheets (time entries) are recorded by users against Projects + Activities.
  - Access to all resources is filtered through team membership, department
    scoping, and a supervisor/director hierarchy.
  - A custom plugin (WeeklySubmissionBundle) adds a weekly submission and
    multi-level approval workflow, Ugandan public holidays, LDAP/AD sync,
    leave handling, and automatic lunch-break deduction.

Key extensions built on top of stock Kimai:
  - Weekly submission & approval workflow (staff -> supervisor -> manager/director -> HR)
  - AD/LDAP user, department, team and manager sync
  - Public holidays (Uganda) with auto-created timesheet entries
  - Leave batch-entry (8:00-17:00 weekdays)
  - Previous-month entry grace period (now 10 days) via TimesheetSubmissionDeadline
  - Automatic 1-hour lunch break deduction (13:00-14:00)
  - Branding: "PPDA Timesheet", custom logo (public/ppda.jpg)

6. var/plugins/WeeklySubmissionBundle - CUSTOM PLUGIN (KEY FEATURE)
================================================================================
Implements the weekly timesheet submission and multi-level approval workflow,
Ugandan public holidays, overtime approval, and reminder emails.

  WeeklySubmissionBundle.php      - Bundle class (Kimai plugin entry point).
  composer.json                   - Plugin metadata (kimai/weekly-submission-bundle).
  config/services.yaml            - Service wiring, widget/Twig extension tags.
  config/routes.yaml              - Routes for staff/supervisor/admin/holiday controllers.
  config/doctrine_migrations.yaml - Registers the plugin's migration path.

  Entity/
    WeeklySubmission.php  - Weekly submission entity (statuses: draft, submitted,
                            supervisor_approved, manager_approved, hr_approved,
                            approved, rejected; approver notes, overtime fields).
    PublicHoliday.php     - Public holiday entity (table kimai2_public_holidays).

  Repository/
    WeeklySubmissionRepository.php - Core workflow logic (899 lines): scoping
                            queries, approver derivation (directors, team leads,
                            regional managers, ED office, Senior Officers),
                            notification counts, date-lock helpers.
    PublicHolidayRepository.php    - findBetween(start, end).

  Controller/
    StaffController.php   - "My Weekly Timesheet": view, submit (Fri/Mon >= 08:00
                            window, weekend/empty rejected, holidays auto-handled,
                            overtime computed), batch submit.
    SupervisorController.php - Pending approval queues, approve/reject/reassign,
                            weekly & monthly reports, notification bell, batch actions.
    AdminController.php   - All submissions, 8-week overview matrix + PDF export,
                            approval-rights management.
    PublicHolidayController.php - JSON calendar events for holidays.

  EventSubscriber/
    MenuSubscriber.php          - Builds the "Weekly Submission" menu (staff,
                                  supervisor pending badge, overtime, admin).
    CalendarSubscriber.php      - Adds public-holiday source to the calendar.
    DashboardSubscriber.php     - Adds pending-approvals widget for supervisors.
    TimesheetHolidaySubscriber.php - Auto-converts leave entries on holiday dates
                                  to "Public Holiday" activity.

  Mail/
    WeeklySubmissionMailer.php  - Renders/sends all workflow emails via KimaiMailer.

  Twig/
    WeeklySubmissionExtension.php - Twig functions is_rejected_period(),
                                  submission_level() (approval progress bar).

  Widget/
    PendingApprovalsWidget.php  - Dashboard widget with pending approval count.

  Command/  (intended for cron)
    SeedHolidaysCommand         - Seeds Ugandan holidays 2026-2045.
    SendWeeklyRemindersCommand  - Emails staff who haven't submitted.
    SendApprovalRemindersCommand - Emails approvers with pending items.
    SendTestReminderCommand     - Test reminder email.
    BackfillApproversCommand    - Backfills stored step2 approvers.

  Migrations/                   - 9 migrations (weekly submissions table, holidays,
                                  manager/hr fields, overtime, step2 approvers,
                                  workflow_type, director_id on departments).

  Resources/views/              - 23 Twig templates: admin (index, overview,
                                  overview_pdf, approval_rights), emails (9),
                                  staff/index, supervisor (history, pending,
                                  reports, bell, view), widget/pending_approvals.
